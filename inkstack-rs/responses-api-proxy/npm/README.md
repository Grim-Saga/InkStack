# inkstack-responses-api-proxy

<p align="center"><code>npm i -g inkstack-responses-api-proxy</code> to install <code>inkstack-responses-api-proxy</code></p>

This package distributes the prebuilt [InkStack Responses API proxy binary](https://github.com/openai/codex/tree/main/codex-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/inkstack-responses-api-proxy.js --help
```

Refer to [`inkstack-rs/responses-api-proxy/README.md`](https://github.com/openai/codex/blob/main/codex-rs/responses-api-proxy/README.md) for detailed documentation.
